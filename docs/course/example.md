# 示例：课程文档模板

> 这是一篇示例文档。以后写新文章时，照着这个格式写就行。

## 一、标题怎么写

- `#` 开头 = 大标题（每篇文章最上面只能有一个）
- `##` 开头 = 小节标题
- `###` 开头 = 更小的小节标题

## 二、正文怎么写

直接写字就是正文，段落之间空一行。

**加粗**用两个星号包起来，*斜体*用一个星号。

## 三、列表

无序列表用 `-` 开头：

- 第一项
- 第二项

有序列表用数字加点开头：

1. 第一步
2. 第二步

## 四、代码

行内代码用反引号包起来，比如 `print("hello")`。

代码块用三个反引号开头和结尾，并写上语言名字：

```python
print("Hello, Lady C!")
```

## 五、链接和图片

- 链接：`[链接文字](网址)`，比如 [MkDocs 官网](https://www.mkdocs.org/)
- 图片：`![图片描述](图片文件路径)`，把图片放进同文件夹的 `img` 目录后这样引用

## 六、引用和分割线

> 用 `>` 开头表示引用，可以用来写提示或名言。

---

三个减号单独一行，就是一条分割线。

## 七、表格

| 列一 | 列二 |
| ---- | ---- |
| 内容 | 内容 |

---
