# 保研经验贴

## 大三前我干了什么

刚上大一，姐姐说了解一下保研。当时并不了解很多，但猜想保研和成绩肯定挂钩吧。大一上学期成绩8/49，略微看了一点别人的经验贴，觉得这个成绩就是边缘人，最多保本校，于是开始了努力、焦虑、快乐、痛苦交织的两年半大学生活。

大一下学期想努力提高成绩，同时了解了研究生想要学的方向，了解了一点考研，还去听了保研分享会，但最终大一一年的成绩只提了1名，变成了7/49。

成绩好难提，于是大二开始不再想着提成绩和保研，而是决定将来还是要考研。

由于文科专业课程成绩给分都很高，所以每次各种小测得的分很高时，总会告诫自己，不要像大一的时候一样太自以为是，别人都很高。直到一次小的期中考试，老师是在全班同学面前录成绩，发现在大家有很大一部分人不及格，以及只有4个人考到80分以上的情况下，我考了95，突然又觉得自己又有保研的机会了。

大二每天开心学习，很累也很快乐，虽然经常焦虑，但感觉自己在一点点进步。最后大二成绩是3/47。

## 大三一年我干了什么

大三上学期专业课多了也难了，上学期主要做的是努力提成绩，目标是在夏令营之前把前五学期成绩提得尽量高。幸运地是因为疫情，第五学期期末考试是寒假回来考的，在家的时候就疯狂复习。最终前五学期成绩是2/47。

大三下学期刚开始非常闲，每天焦虑投什么学校，怎么准备复试，怎么写个人陈述、简历、推荐信、参营论文。当时从b站上看了一点别人的经验，都试了一下选择了适合自己的复试准备方式准备了一段时间。后来决定先准备参营论文，整个五一看了五天的文献。后来上交夏令营简章率先发出，逼着我完成了个人陈述、推荐信、证件照、各类证书扫描件，花一天的时间投完了第一所学校。

后面就是准备投递和参营。准备参营论文心力交瘁，每天要复习准备专业课的各种期中考试，要花时间和心思投递很大程度不会入营的学校，准备各种材料，跑教务处给材料盖章。这一段时间睡眠时间非常少，经常一两点睡，五六点起，最累的是期末考试的时候，两点半睡，三点半起，甚至经历了人生第一次通宵复习完一门专业课。

最值得一提的是，我在做这些事情时，舍友也做着同样的事情，我们有事互相商量。如果没有舍友，我可能坚持不下去投这么多学校。
